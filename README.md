## ✨ Features

### 🛍 Customer Experience
- **Luxury Branding:** Custom gold calligraphy emblem and animated reveal GIF loader.
- **Hero Showcase & Sliders:** Dynamic carousel banners with auto-advance and call-to-actions.
- **Product Catalog & Filtering:** Live search, parent/child category filtering, price bounds, sorting, and pagination.
- **Product Details:** Multi-angle gallery, variation selector (color, size, stock indicator), verified customer reviews, and star ratings.
- **Real-Time Cart:** Immediate subtotal calculations, dynamic delivery calculations (Free on Rs. 3,000+), quantity steppers.
- **Pakistani Bank Checkout:** Preconfigured with Habib Bank Limited (HBL) and MCB Bank account numbers, plus receipt screenshot upload.
- **Live Order Milestone Tracker:** Real-time visual pipeline (`received` → `packing` → `dispatched` → `delivered`).
- **Account & Security:** Profile updates, order history, and self-service password reset via signed email links.

### 🛡 Admin Operations (`/admin`)
- **Executive Analytics:** Metric cards (Revenue, Volume, AOV), Recharts visual graphs, and live WebSocket notification alerts.
- **Product & Stock Manager:** Multi-variation creator, multi-image upload directly to MongoDB GridFS, automatic SEO slug and keyword generator.
- **Order Lifecycle Controls:** Status updater, payment confirmation, and direct receipt screenshot viewer (`📎 Receipt`).
- **Review Moderation:** Approve/unapprove incoming reviews before public display, plus official store replies.
- **Payment & Bank Config:** Manage bank accounts (HBL, MCB, etc.) and audit customer payment confirmations.
- **Promotions & Sliders:** Schedule homepage banner slides and percentage discounts.

## 🚀 Installation

### Prerequisites
- **Python:** 3.12 or newer
- **Node.js:** 18.0+ and npm
- **MongoDB:** 7.0+ (Running locally on `mongodb://localhost:27017` or a MongoDB Atlas URI)

---

### Backend Setup

1. **Enter backend directory:**
   ```bash
   cd backend
   ```

2. **Create and activate a virtual environment:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. **Install pinned dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Initialize environment variables:**
   ```bash
   cp .env.example .env
   ```

5. **Populate initial database (Categories, Products, Admin, Bank Accounts):**
   ```bash
   PYTHONPATH=. .venv/bin/python seed.py
   ```

6. **Start the backend server (Port 8015):**
   ```bash
   .venv/bin/uvicorn app.main:app --reload --port 8015
   ```

---

### Frontend Setup

1. **From repository root, install Node dependencies:**
   ```bash
   npm install
   ```

2. **Verify or create frontend `.env`:**
   ```bash
   echo "VITE_API_URL=http://localhost:8015" > .env
   ```

3. **Start the Vite development server (Port 5173):**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

## ⚡ Usage Examples

### Customer Workflow
1. Visit [http://localhost:5173](http://localhost:5173).
2. Explore collections or search for *"Waistcoat"*, *"Kurta"*, or *"Shalwar Kameez"*.
3. Pick your desired color and size, then click **Add to Cart**.
4. Log in as a customer:
   - **Email:** `ahmed@example.com`
   - **Password:** `customer123`
5. Proceed to **Checkout**, verify bank payment details, and complete your order.
6. Upload your bank payment receipt screenshot (`.png`, `.jpg`, `.jpeg`).

### Admin Dashboard
1. Log in with the administrative credentials:
   - **Email:** `admin@hamidcloth.com`
   - **Password:** `admin123`
2. Navigate to [http://localhost:5173/admin](http://localhost:5173/admin) or select **Admin Dashboard** in the user menu.
3. Review pending orders, verify customer uploaded receipts (`📎 Receipt`), update statuses, and approve customer reviews.
